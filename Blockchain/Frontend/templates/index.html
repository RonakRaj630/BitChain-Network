How It Works
Real Bitcoin concepts implemented from scratch
🔐
secp256k1 ECC
Real elliptic curve cryptography using the exact same curve as Bitcoin. Private keys, public keys, and ECDSA signatures all implemented in pure Python.
⛏️
Proof of Work
SHA-256 double-hash mining with adjustable difficulty target. Miners compete to find a nonce that produces a hash below the target.
📜
P2PKH Scripts
Pay-to-Public-Key-Hash script execution with OP_DUP, OP_HASH160, OP_EQUALVERIFY, and OP_CHECKSIG — just like real Bitcoin transactions.
🌐
P2P Network
Multiple miners can connect and sync. Blocks are broadcast to peers as they're mined. New nodes download and verify the full chain on join.
💰
UTXO Model
Unspent Transaction Output tracking in memory, just like Bitcoin. Spend verification checks the UTXO set before including transactions in blocks.
🌳
Merkle Tree
Transaction IDs are hashed into a Merkle root stored in the block header, allowing efficient transaction inclusion proofs.
